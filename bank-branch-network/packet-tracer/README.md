# Packet Tracer project

`Bank.pkt` is the complete lab topology (2911 router, 2960 switch, 3 PCs, web/mail/FTP servers) with all configs applied. Open it in Cisco Packet Tracer 8.x.

To rebuild from scratch instead, use the scripts in `../configs/setup/` and the server notes in `../servers/`. Lab accounts are listed in `../docs/credentials.md`.
